# 动漫 115

MoviePilot V2 插件。从动漫花园给追更名单补磁力，提交到 MoviePilot 里已经登录的 115 离线，下完后整理进季目录，按需写 strm 并通知 Emby 刷新。整包摊平先做分类，没有安全移动就不改文件。

外壳跟 [mp-115](https://github.com/wyh137815840/mp-115) 的「115 AV刮削」一样：`plugins.v2/`、`package.v2.json`、Vuetify 表单、`只预览` 默认开着。默认只使用 MoviePilot 里已登录的 115 存储 `u115`，不另建客户端；表单里的「115 Cookie」是可选旁路，只有在填了 `UID=` 时才影响整理/摊平/strm，每日离线提交仍走已登录存储。

## 安装

在 MoviePilot 的插件仓库里加入本仓库，或把 `PLUGIN_LOCAL_REPO_PATHS` 指到这个目录。同步插件源后安装「动漫 115」。

也可以把 `plugins.v2/anime115` 复制到 MoviePilot 的 `app/plugins/anime115`。

## 使用

1. MoviePilot 里先登录 115，存储 ID 保持 `u115`。115 Cookie 和「115 AV刮削」同一格式（`UID=...; CID=...; SEID=...; KID=...`）。留空时全部走已登录存储；填了 `UID=` 时，整理、摊平、strm 的列目录/移动改走这条 Cookie，但每日离线提交仍走已登录存储（Cookie 模式的整理需要 MoviePilot 环境里有 `p115client`）。`strm 目录` 先填写。strm 默认写「内网播放地址」（`http://192.168.1.9:3000`），局域网播放不再走 `https://mp.yuanhot.top`。外网播放地址留给公网 Emby 反代。两个地址都不能写 `127.0.0.1`。
2. 默认从 MoviePilot 订阅里只挑动漫（`订阅来源=mp`），每部剧单独搜动漫花园。
   标题比对按剧名整体匹配：剧名只是另一部剧的前缀时不收（《死神》不会收《死神少爷与黑女仆》），
   本剧换了名字的续作会靠 TMDB 别名（BLEACH、千年血战篇）认回来。普通电视剧、电影会跳过。要把表单里的「追更」也纳入，把「订阅来源」改成 `both`；只想用追更框就改成 `watchlist`。追更每行一部：`剧名 | 别名 | group=字幕组 | tmdb_id=编号 | 连载中`。`[05]`、`[01v2]` 这样的集数可以入选，`第2期/Season 2/S2` 也能认成第 2 季；`01-12` 这种范围整包不会被当成单集。标题比对会忽略星号和空格，并把常见繁体折成简体，所以 `魔法★探险家` 能对上 `魔法★探險家`；仍建议把 `Magical Explorer` 写成别名。写了「连载中」才按 TMDB 已播集数封顶；`tmdb_id=` 对不上名字时用来指定剧。插件配置里的 TMDB API Key 填 v3 密钥，留空则用 MoviePilot 系统设置里的 `TMDB_API_KEY`。从 MP 订阅读取时没有别名/字幕组字段，日文或繁体标题建议用 `both` 在追更框里补别名。
3. 离线目录填 115 上的真实路径，例如 `/离线下载/动漫`。日期子目录由插件加。`/115open` 只是旧挂载前缀，填在「挂载前缀」里会被剥掉。
4. 整包（一个种子多集，比如 01-12）会按每集自己文件名里的集数拆开，一集一集搬进季目录，
   每集一个 strm。字幕按当前集匹配，不会每集重复搬整季字幕；同主干的 SC/TC 后缀会保留以避免简繁字幕撞名。
   本机下载字幕优先走已配置的内网播放入口，视频 STRM 仍保持所选的公网/内网模式；已有非空本地字幕不重复下载覆盖。
   明确的 PV、CM、MENU、NCOP/NCED、Yokoku 等花絮不当正片入库；Mini/SP 和异名短篇不混作正片多版本。
   不连号时，只有任务标题与包目录声明同一范围、剩余编号均在范围内，才继续搬剩余集；否则留在原地，不猜集数、不重编号。
   季目录里如果已经多套了一层包目录，用 `POST /api/v1/plugin/Anime115/run?job=split` 拆开。
5. 库根填整理目标，例如 `/动漫`。搬过去的形状是 `剧名/Season 01/原来的文件名`。
   找包按「剧名核心词 + 集数」认：115 上落地用的是种子原名，和动漫花园重命名后的标题对不上，
   只按名字全等会找不到。认不准仍然留在收件箱，不会搬错包。整理会翻完整份 115 离线列表，不限前 5 页。已经不在列表里、但还在 `/离线下载/动漫/YYYYMMDD` 的提交也会入库。整理成功后写 strm；季目录里已有同集视频时不叠 strm。
5. 默认「库里已有同集不提交」是开着的：选片时会先查库根/剧名/季目录，已经有这一集就跳过，不重复下载。查不到（没填库根、目录认不准、115 接口失败）时按没有处理，不会挡住正常提交。先保持「只预览」，每日任务只会列出将要提交的磁力。
6. 确认后再关掉「只预览」。摊平还要另外打开「摊平允许落盘」。全是碰撞或不确定时，摊平一次都不移动。
7. 需要 Emby 刮削时，打开「完成后刷新 Emby」，并把「Emby 媒体库名」填成 Emby 里的库名（默认 `动漫`）。只在整理或 strm 真正写盘后刷新这一库；找不到同名库就不刷（不会回退刷新全部库），预览模式不刷。MoviePilot 里需要已经配置好 Emby 连接。
8. 「发送通知」打开后，成功和失败都会推送；失败包括 115 未登录、配额用尽、离线/整理/strm 出错。预览且没有任何动作时保持安静。

所有 115 调用都有时限：列目录、建目录、移动、删除各 60 秒，离线列表和配额 45 秒。每一轮任务还有 15 分钟的总预算；单条整理扫描预算为 2 分钟，大包搬运按文件数和搬运间隔增加有限预算（最多 10 分钟，且不突破整轮截止时间）。超时收尾，未完成的留到后续轮次。115 卡住或触发风控时不会把整轮任务拖死——超时的那一条记成失败并留在待整理里，下一轮再试。

每日补磁力和整包摊平留空则不定时。离线整理留空也会注册「动漫离线整理」，周期是 `*/30 * * * *`（MoviePilot 宿主机时区，和每日任务同一个调度器）。已经保存的空 `organize_cron` 会在插件加载时写成这个默认值。打开「保存后立即跑一次每日任务」，或调用 `POST /api/v1/plugin/Anime115/run?job=daily|organize|flatten|strm`（`strm` 可加 `root=某一剧目录`）。

动漫花园走 MoviePilot 系统设置里的代理（`PROXY_HOST`）。没填就直连。容器里直连若出现 `SSL: UNEXPECTED_EOF_WHILE_READING`，把代理填进 MoviePilot，不要改插件代码。日志里会写「经系统代理拉取」或「直连拉取」。

## 内网播放

1.0.18 起，新写的 strm 用内网播放地址。更新后在 MoviePilot 里重载「动漫 115」，不必重启容器。

已经落在盘里的动漫 strm 不会自动改。重载并确认「strm 使用的地址」是 `lan` 之后，调用 `POST /api/v1/plugin/Anime115/run?job=strm` 重新生成。整理新入库的文件也会按这个地址写。

公网好友要播时，把插件详情页里的 nginx 片段加到 Emby 的公网反代，不要加到局域网入口。AV 库的 strm 由 mp-115 的「115 AV刮削」生成，不在这次改写范围内，需要在那边改播放地址或另行重新生成。
